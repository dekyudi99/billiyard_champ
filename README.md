# Billiard Championship - World Esports Management System

Sistem web terintegrasi dan otomatis berbasis Docker untuk mengelola seluruh ekosistem turnamen Billiard Championship (MPL di 7 Region, MSL Championship, M World Championship, Road to World, Base Team, dan Base Region).

## 🚀 Jalankan Aplikasi via Docker

```bash
docker compose up --build
```

Lalu buka di browser: **[http://localhost:8000](http://localhost:8000)**.

Dokumentasi lengkap sistem, aturan kualifikasi slot M4 & MSL S4, serta arsitektur teknis dapat dilihat di [web-app/README.md](web-app/README.md).
